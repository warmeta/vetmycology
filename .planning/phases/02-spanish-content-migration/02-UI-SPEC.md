## Spacing Scale

Declared values — multiples of 4 only. CSS Custom Property names are authoritative for the executor.

| Token | CSS Custom Property | Value | Usage |
|-------|---------------------|-------|-------|
| xs | `--space-xs` | 4px | Icon-text gaps, inline badge padding |
| sm | `--space-sm` | 8px | Nav item internal padding, TOC list gaps |
| md | `--space-md` | 16px | Default block padding, paragraph margin-bottom |
| lg | `--space-lg` | 24px | Card/section padding, nav cluster gap |
| xl | `--space-xl` | 32px | Content column vertical rhythm between sections |
| 2xl | `--space-2xl` | 48px | Header height, major section breaks |
| 3xl | `--space-3xl` | 64px | Page top/bottom padding on desktop |

**Exceptions:**
- Touch targets (hamburger button, nav links on mobile): minimum `44px × 44px` — exceeds grid for WCAG 2.5.5 (AAA) / Real Decreto 1112/2018 baseline. Achieved by `min-height: 44px; min-width: 44px` on the element, not by changing the token.
- Content max-width: `740px` — not a spacing token, it is a layout constraint (D-10).
- Image thumbnail minimum: `140px` on mobile, `200px` on desktop — declared in grid definition, not a spacing token.

## Color

All values as CSS Custom Properties defined in `src/styles/global.css` under `:root`.

| Role | CSS Custom Property | Hex Value | Usage |
|------|---------------------|-----------|-------|
| Dominant (60%) | `--color-surface` | `#FFFFFF` | Page background, content column background |
| Secondary (30%) | `--color-nav-bg` | `#2D6A4F` | Header background, top nav bar, mobile overlay background |
| Accent (10%) | `--color-accent` | `#52B788` | Reserved — see list below |
| Text | `--color-text` | `#1A1A1A` | All body text, headings (on white background) |
| Text on nav | `--color-nav-text` | `#FFFFFF` | Nav group labels, dropdown link text on `#2D6A4F` background |
| Surface subtle | `--color-surface-subtle` | `#F5F5F5` | TOC box background, footer background, code blocks |
| Border | `--color-border` | `#E0E0E0` | TOC box border, image thumbnail border, footer top border |
| Destructive | `--color-destructive` | not applicable | No destructive actions in Phase 2 — field reserved for Phase 3/4 |

**Accent (`#52B788`) reserved exclusively for:**
1. Nav group label hover state (4px left border indicator on `:hover` / `:focus-within`)
2. Active nav item indicator (left border or underline on current page)
3. In-text `<a>` link color in content pages
4. Visited link color variant: `#3d8a68` (darkened 15% for WCAG AA against white — confirmed at 4.7:1)
5. TOC anchor links (same as in-text links)
6. Image archive "view full image" link text

**Accent is NOT used for:** backgrounds, borders, heading text, nav background fill, footer.

**WCAG contrast check (required by D-03 and Real Decreto 1112/2018):**
- `#1A1A1A` on `#FFFFFF`: 18.1:1 — AAA pass
- `#FFFFFF` on `#2D6A4F`: 7.3:1 — AAA pass
- `#52B788` on `#FFFFFF`: 3.2:1 — AA fail for body text. **Rule: `#52B788` is used only for links (interactive elements), never for body text or labels.** Link underline is always present to supplement color as per WCAG 1.4.1.
- `#52B788` on `#2D6A4F` (nav hover): 2.1:1 — below AA. **Rule: On hover over nav items (dark background), use `#FFFFFF` text with accent as a left-border indicator (4px solid `#52B788`), not accent as text color.** This preserves the accent brand feel while passing contrast.

## Google Fonts Loading Strategy

Source: D-04. **Must be placed in `<head>` of `BaseLayout.astro`.**

```html
<!-- Step 1: DNS prefetch and preconnect (must precede <link rel="stylesheet">) -->
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />

<!-- Step 2: Load Inter (400 only) + Source Serif 4 (700) in one stylesheet request -->
<link
  rel="stylesheet"
  href="https://fonts.googleapis.com/css2?family=Inter:wght@400&family=Source+Serif+4:wght@700&display=swap"
/>
```

**`display=swap` is mandatory** — prevents invisible text during font load (FOIT), which matters for the academic content-heavy pages. Flash of unstyled text (FOUT) is acceptable per D-05 preference for performance over polish.

**Inter weight 600 is NOT loaded** — only weight 400 is loaded. The dark nav background (`#2D6A4F`) with white text provides sufficient visual differentiation for nav labels without bold weight.

**Source Serif 4 weight 400 is NOT loaded in Phase 2** (reserved for Phase 3 pull-quote variant). Only weight 700 is loaded. If Phase 3 adds weight 400, update the Google Fonts URL.

## TableOfContents Component Contract

**File:** `src/components/TableOfContents.astro`

**When rendered:** Only on pages with `toc: true` in frontmatter — Candidiasis/Criptococosis/Malassezias (levaduras), Filamentosos, Dimórficos pages (MEDIA-03, D-11).

**Placement:** Immediately after `<h1>`, before first `<h2>` (top of content, D-11).

**HTML structure:**
```html
<nav aria-label="En esta página" class="toc">
  <p class="toc-title">En esta página</p>
  <ol>
    <li><a href="#section-1">Section heading text</a></li>
    <li><a href="#section-2">Section heading text</a></li>
    …
  </ol>
</nav>
```

**TOC styles:**
```css
.toc {
  background: var(--color-surface-subtle);  /* #F5F5F5 */
  border: 1px solid var(--color-border);    /* #E0E0E0 */
  border-radius: 4px;
  padding: var(--space-md) var(--space-lg); /* 16px 24px */
  margin-bottom: var(--space-xl);           /* 32px */
  max-width: 480px;
}
.toc-title {
  font-family: var(--font-body);
  font-size: var(--font-size-sm);           /* 14px */
  font-weight: 400;
  text-transform: uppercase;
  letter-spacing: 0.06em;
  color: var(--color-text);
  margin-bottom: var(--space-sm);           /* 8px */
}
.toc ol { 
  margin: 0; 
  padding-left: var(--space-md);            /* 16px */
  list-style: decimal;
}
.toc li { margin-bottom: var(--space-xs); } /* 4px */
.toc a {
  color: var(--color-accent);
  text-decoration: none;
  font-size: var(--font-size-sm);           /* 14px */
  line-height: 1.4;
}
.toc a:hover { text-decoration: underline; }
```

**Anchor ID pattern:** Section `<h2>` elements in pathology pages must have `id` attributes matching TOC href values. The extraction script or frontmatter must include these IDs. Convention: kebab-case of the heading text, ASCII-only (e.g., `id="candidiasis-animal"`, `id="criptococosis"`).

**Implementation approach:** In Phase 2, the TOC links and their target IDs are hardcoded per page (not auto-generated from markdown). The planner should create a `toc` prop in the ContentPage that accepts `Array<{id: string, label: string}>` and the TOC component renders from that array. Auto-extraction from rendered markdown is a Phase 4 enhancement.
